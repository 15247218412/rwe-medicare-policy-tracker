# Codex Automation 最终提示词

请在当前仓库执行“全国真实世界医保综合价值评价增量监测”。

严格遵守仓库根目录 `AGENTS.md`。

本次任务必须：

1. 读取历史数据库、最近报告、官方站点种子表和关键词表；
2. 检索国家医保局、31个省级医保部门、试点先行地区、已知可信评价点及相关官方机构自上次运行以来的新进展；
3. 检索时向前回溯至少7天，避免遗漏延迟收录网页；
4. 优先使用官方原始网页；行业媒体只能作为发现线索；
5. 与 `data/master.csv` 比较，只将真正新增或发生实质变化的信息写入本期结果；
6. 对同一新闻转载进行去重，优先保留首发官方来源；
7. 更新：
   - `data/master.csv`
   - `data/latest.csv`
   - `data/regions.csv`
   - 必要时 `data/documents.csv`
   - 发生变化的 `provinces/*.md`
8. 生成 `reports/YYYY-MM-DD.md` 增量报告；
9. 每条重要记录保留原始网页 URL；如有政策附件，记录附件名称和原始附件 URL；
10. 对无法确认的线索标记“待核实”，不得自行补全事实；
11. 运行仓库脚本进行标准化、去重和报告检查；
12. 检查 `git diff`，如有实际更新则创建 commit：`monitor: YYYY-MM-DD 增量更新`；
13. 如果环境允许 push，则推送到当前分支；若没有 push 权限，明确说明“已本地提交，未推送”，不要声称已完成远程推送。

如果本期没有重大新增，也必须生成一份简短报告并更新运行日期，写明“本期未发现重大新增进展”，不要为了产生内容而收录低价值重复新闻。

最终向我汇报：
- 新增条数；
- 更新条数；
- 最重要的3—5条变化；
- 待核实条数；
- 本次修改的文件；
- commit/push 状态。
